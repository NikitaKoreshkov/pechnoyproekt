# 🔒 Настройка SSL сертификата

## ✅ Текущий статус (настроено)

- Домен **aquagazteh.ru** указывает на сервер **168.222.193.132**
- Nginx проксирует запросы на Next.js (порт 3000)
- Установлен SSL-сертификат Let's Encrypt для **aquagazteh.ru** и **www.aquagazteh.ru**
- HTTP автоматически перенаправляется на HTTPS
- Автообновление сертификата: таймер certbot (certbot.timer)

Сайт доступен: **https://aquagazteh.ru**

## ✅ Что было сделано на сервере

- Nginx: конфиг `/etc/nginx/sites-available/aquagazteh.ru`
- Certbot: сертификат в `/etc/letsencrypt/live/aquagazteh.ru/`
- Проверка продления: `certbot renew --dry-run`

## 🔧 Решение: Настройка DNS

### Вариант 1: Настроить DNS запись (рекомендуется)

1. Зайдите в панель управления вашего домена
2. Найдите настройки DNS записей
3. Измените A-запись для `aquagazteh.ru`:
   - **Имя:** `@` или `aquagazteh.ru`
   - **Тип:** `A`
   - **Значение:** `168.222.193.132`
   - **TTL:** `3600` или `1800`

4. Также настройте для `www`:
   - **Имя:** `www`
   - **Тип:** `A`
   - **Значение:** `168.222.193.132`
   - **TTL:** `3600`

5. Подождите 5-30 минут для распространения DNS (проверьте: `dig aquagazteh.ru`)

6. Когда DNS обновится, выполните на сервере:
   ```bash
   ssh root@168.222.193.132
   bash /root/get_ssl_cert.sh
   ```

### Вариант 2: Использовать Cloudflare (альтернатива)

Если домен использует Cloudflare:
1. Подключите домен к Cloudflare
2. Измените A-запись на `168.222.193.132`
3. Используйте DNS challenge для получения сертификата:
   ```bash
   certbot certonly --dns-cloudflare --dns-cloudflare-credentials /root/cloudflare.ini -d aquagazteh.ru -d www.aquagazteh.ru
   ```

## 📋 Проверка DNS

Проверить, указывает ли домен на правильный IP:

```bash
# На локальном компьютере
dig +short aquagazteh.ru
# Должно вернуть: 168.222.193.132

# Или
nslookup aquagazteh.ru
```

## 🔄 После настройки DNS

Когда DNS будет указывать на `168.222.193.132`, выполните:

```bash
ssh root@168.222.193.132
bash /root/get_ssl_cert.sh
```

Сертификат будет автоматически получен и установлен, самоподписанный сертификат будет заменен на Let's Encrypt.

## 🔍 Текущая конфигурация

- **Самоподписанный сертификат:** `/etc/nginx/ssl/site.crt`
- **Ключ:** `/etc/nginx/ssl/site.key`
- **Nginx конфиг:** `/etc/nginx/sites-available/site`
- **Порт 443:** HTTPS работает
- **Порт 80:** Редирект на HTTPS
