# 📋 Инструкция по настройке и запуску

## Что нужно перед запуском

1. **Node.js 18+** - [скачать](https://nodejs.org/)
2. **PostgreSQL** - [скачать](https://www.postgresql.org/download/)
3. **Git** (опционально)

---

## Пошаговая инструкция

### Шаг 1: Установка зависимостей

```bash
cd site
npm install
```

### Шаг 2: Настройка PostgreSQL

1. Установите PostgreSQL
2. Создайте базу данных:
   ```bash
   psql -U postgres
   CREATE DATABASE mydb;
   \q
   ```

### Шаг 3: Создайте файл `.env`

Создайте файл `.env` в корне проекта (`/site/.env`) со следующим содержимым:

```env
DATABASE_URL="postgresql://postgres:ВАШ_ПАРОЛЬ_POSTGRES@localhost:5432/mydb?schema=public"
NEXTAUTH_SECRET="любая-случайная-строка-минимум-32-символа-например-такая"
NEXTAUTH_URL="http://localhost:3000"
```

**Важно:**
- Замените `ВАШ_ПАРОЛЬ_POSTGRES` на реальный пароль PostgreSQL
- Замените `любая-случайная-строка...` на случайную строку (можно сгенерировать: `openssl rand -base64 32`)

### Шаг 4: Настройка базы данных

```bash
npm run db:push
npm run db:generate
npm run db:seed
```

### Шаг 5: Запуск

```bash
npm run dev
```

Откройте браузер: **http://localhost:3000**

## ❓ Возможные проблемы

### Ошибка подключения к базе данных
- Проверьте, что PostgreSQL запущен
- Проверьте правильность `DATABASE_URL` в `.env`
- Убедитесь, что база данных `mydb` создана

### Ошибка "NEXTAUTH_SECRET not found"
- Убедитесь, что в `.env` есть строка `NEXTAUTH_SECRET=...`
- Значение должно быть минимум 32 символа

### Проекты не показываются
- Выполните `npm run db:seed` для заполнения начальными данными
